# Shrook — GitHub Pages upload

For the exact URL `https://shrookmusic.github.io/`, the repository owner must be a GitHub account or organization named `shrookmusic`, and the repository must be named `shrookmusic.github.io`.

## Upload
1. Extract this ZIP.
2. Upload the extracted contents (not the ZIP itself) to the repository root. `index.html`, `style.css`, the JavaScript files, and `assets/` must be at the root.
3. In GitHub, open the repository's **Settings → Pages**. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then save.

## Track audio
The six local MP3s are intentionally omitted because files in a public GitHub Pages repository can be downloaded directly. Track cards show placeholders. Replace them with streaming embeds or links before launch. The SoundCloud DJ set embeds remain in place.
